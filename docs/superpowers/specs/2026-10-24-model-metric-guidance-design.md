# 模型实验说明设计

## 意图

在模型实验页内解释可执行模型和评价指标，使汽车企业与研究人员能够在选择模型、阅读测试结果时就地理解其用途、判断方向与局限，不需要离开当前实验上下文查阅外部材料。

## 范围

- 为 Ridge、随机森林、XGBoost、LightGBM、BEAST-MCDM 提供简短常驻摘要，以及可展开的“原理 / 适用价值 / 注意事项”。
- 为 R²、WAPE、RMSE、MAE 提供中文名称、含义、判断方向和解释边界。
- 明确负 R² 表示结果劣于直接使用测试集均值作为基准；WAPE 以比例显示且越低越好；RMSE 对较大误差更敏感；MAE 表示平均绝对偏差。
- 说明四项指标均基于当前运行的测试月份计算，不能脱离数据切分、车型范围和样本量横向比较。
- 保持说明与模型能力列表和结果表相邻；不改变后端模型、计算公式、实验数据或既有运行记录。

## 展示方案

采用方案 A：渐进式就地说明。

- 模型选择卡保留现有勾选操作，在版本信息下增加一句摘要；下方增加一个统一的“了解模型”展开区域，按模型列出原理、适用价值和局限。
- 实验结果区域增加常驻的指标说明网格，四项指标各占一个紧凑说明单元；表头仍保留 `↑ / ↓`，说明单元补充如何解释数值。
- 无实验结果时也显示模型说明；指标说明放在结果区中，只有进入结果阅读上下文时出现。
- 使用原生 `details/summary` 与现有样式体系，保证键盘可用、无需新增依赖、避免弹窗和悬浮提示遮挡数据。

## 考虑过的方案

- 独立“模型与指标手册”：信息容量高，但会切断实验操作与解释之间的联系，未采用。
- 仅使用悬浮提示：视觉最轻，但触屏、键盘和长文本体验较差，未采用。
- 渐进式就地说明：兼顾即时理解、页面密度与可访问性，已选用。

## 验收标准

- 五个模型均能在模型选择区域找到准确说明。
- 四个指标均能在结果区域找到含义、方向和注意事项。
- 页面明确解释负 R²，不把任何单一指标描述为模型优劣的充分结论。
- 原有模型选择、运行、历史记录和结果表行为不变。
- 新增前端契约测试先失败后通过，完整前端测试、类型检查、格式检查、设计契约与生产构建通过。

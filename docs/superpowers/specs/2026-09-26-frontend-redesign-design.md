# 观衡前端重设计规格

- 状态：已实现并验收
- 日期：2026-09-26
- 参考前端：`E:\aaaxz\daima1022\DZagent\frontend`
- 目标版本：观衡 `0.1.x` 的视觉与交互重设计，不改变研究数据口径

## 1. 背景与目标

观衡已经具备六个可运行页面、项目与准则版本管理、数据导入导出及研究归档展示，但现有深色侧栏和大面积研究展示语言与后续面向企业分析人员、研究人员的长期工作台定位仍有距离。

本次重设计借鉴参考项目的机构化工作台设计语法：浅灰画布、浅色侧栏、紧凑顶栏、低阴影卡片、细分隔线、中文衬线标题和高密度数据布局。参考项目的校徽、校园图片、党建红和具体品牌资产不进入观衡。

成功标准：用户进入系统后能快速确认当前项目、月份和准则版本；六个页面具有统一且克制的研究工具气质；信息密度提高但不牺牲可读性；桌面、平板和手机均可完成现有流程。

## 2. 范围

### 2.1 包含

- 重设计应用壳、品牌区、主导航、顶栏和移动导航。
- 统一页面标题、上下文控制条、指标区、卡片、按钮、表单、表格、提示、空状态和对话框。
- 调整六个现有业务页面的视觉层级与必要的展示结构。
- 统一 ECharts 的字体、颜色、网格线、图例、提示框和无动画默认。
- 拆分前端样式文件，保持职责清晰。
- 完成桌面、平板、手机和减少动效模式的浏览器验收。

### 2.2 不包含

- 不修改后端 API、SQLite schema、研究归档或算法逻辑。
- 不改变份额分母、准则版本、月份、指标或实验结论口径。
- 不加入登录、权限、协作、自适应评估或第二项研究。
- 不复制参考项目的院校图片、校徽、文字标识或业务文案。
- 不引入 PrimeVue、Tailwind、GSAP、外部字体或新的运行依赖。

## 3. 设计方向

设计主题为“新能源汽车科研工作台”。视觉应严谨、克制、可复核，不采用营销落地页、大面积渐变、玻璃拟态或装饰性动画。

### 3.1 色彩令牌

| 角色 | 色值 | 用途 |
| --- | --- | --- |
| 研究画布 | `#F3F5F6` | 页面背景 |
| 数据表面 | `#FFFFFF` | 侧栏、顶栏、卡片、表格 |
| 墨色 | `#1E2B38` | 标题、主要正文 |
| 结构线 | `#D9E0E5` | 边框、分隔线、网格线 |
| 评论信号青 | `#0F7C82` | 主操作、评论/准则语义、当前状态 |
| 市场响应橙 | `#C65A3A` | 销量/市场语义、需关注状态 |

柔和背景色、悬停色和次级文字色从上述令牌派生，不另设无意义的品牌色。

### 3.2 字体角色

根据最终验收要求，展示标题、正文与控件、数据与月份、ECharts 图表统一使用 `SimSun`、`宋体`、`STSong`、`Songti SC`、`serif` 回退链。仍保留展示、正文、数据三个语义令牌，方便后续在不改组件的情况下调整排版，但当前三个令牌取值一致。

不下载网络字体，确保离线运行和中文覆盖稳定。

### 3.3 识别元素

应用壳顶部使用一条克制的双色“证据链轨道”：青色代表评论与准则信号，橙色代表销量与市场响应。它编码真实研究链路，不扩散成大面积渐变或无意义装饰。

## 4. 信息架构与应用壳

桌面结构：

```text
┌──────── 232px 浅色侧栏 ────────┬──────── 64px 顶栏 ───────────┐
│ 品牌与系统名称                 │ 研究空间 / 当前页面    用户  │
│ 当前项目简报                   ├──────────────────────────────┤
│ 六个业务导航                   │ 页面标题、说明、主要操作      │
│                                │ 项目 / 月份 / 版本控制条      │
│ 数据来源与版本                 │ 页面业务内容                  │
└───────────────────────────────┴──────────────────────────────┘
```

- `App.vue` 继续创建并提供唯一 workspace，只承担应用壳、导航、页面映射、全局状态面和新建项目对话框。
- 侧栏为浅色固定区域，包含紧凑品牌锁定、系统名、六项导航和数据来源说明。当前项使用淡青底、左侧识别线和 `aria-current`。
- 顶栏固定显示研究空间、当前页面、阶段说明与本机用户标识；底部细双色轨道标识数据链路。
- 内容区域使用可读最大宽度，不让超宽屏把表格和图表拉散。
- 页面标题区包含眉题、标题、说明和一个主要操作；不重复顶栏已有信息。
- 项目、观察月份、准则版本和模式进入统一上下文控制条，切换时保持现有请求与并发保护逻辑。

## 5. 页面设计

### 5.1 研究总览

- 四项统计使用连续指标带和垂直分隔线，不生成四张重复卡片。
- 权重图为主视觉；“本月观察”为辅助解释区，保持约 2:1 的桌面宽度。
- 研究流程使用真实五阶段语义；阶段序号仅因其确有顺序而保留。
- 归档限制和数据来源贴近图表与导出操作，不隐藏在页尾。

### 5.2 数据中心

- 数据集名称、记录数、导入/导出位于同一页头。
- 搜索、月份说明和份额分母说明形成统一工具条。
- 表头保持可扫描，数字右对齐，表格自身允许水平滚动。
- 空结果明确说明是无数据还是搜索条件无匹配，并提供下一步操作。

### 5.3 准则工作台

- 版本选择、草稿/冻结状态和保存操作固定在面板头部。
- 每条准则呈现序号、名称、有序等级、等级数和删除操作。
- 编辑态与只读态保持相同结构，避免冻结后页面跳变。
- 冻结和派生版本继续使用现有确认、并发修订和未保存保护。

### 5.4 情景分析

- 曲线类型分段选择器、准则筛选和图例组成分析控制区。
- 图表作为主要画布；说明和数据表放在其后，详细数据默认折叠。
- 准则颜色稳定，不能因筛选顺序改变；隐藏曲线后仍保留可访问名称。

### 5.5 份额分析

- 真实份额和估计份额在图表与表格中使用一致顺序和颜色。
- 差值同时使用符号、文字/数值和颜色表达，避免只依赖红绿。
- 搜索仅过滤展示的口径说明保持可见。

### 5.6 实验档案

- 基线与消融实验共享指标列、数值格式和模型高亮规则。
- “原研究归档”作为来源状态而不是装饰徽章。
- 训练测试重叠限制在表格前明确展示，不把档案指标描述成系统重训结果。

## 6. 组件和样式边界

不建设完整组件库，只提取确有复用或独立生命周期的单元。

- 新增 `frontend/src/components/AppBrand.vue`，负责观衡标识和紧凑/完整两种呈现。
- 不新增通用 `PageHeading` 组件；当前页面标题由应用壳统一拥有，使用语义类保持一致，避免为单一调用建立包装层。
- `Chart.vue` 继续独占 ECharts 初始化、重绘、尺寸响应、ARIA 和销毁；业务 option 留在各 view。
- 本次不修改 `workspace.ts` 和 `api.ts`。如果实现中发现视觉需求必须改变共享状态或接口，停止实现并先修订本规格。

将 `frontend/src/style.css` 改为样式入口，并拆分为：

```text
frontend/src/styles/foundation.css  令牌、reset、排版、焦点和辅助类
frontend/src/styles/shell.css       应用壳、侧栏、顶栏、导航、对话框
frontend/src/styles/components.css  按钮、输入、徽章、卡片、表格、提示
frontend/src/styles/pages.css       指标带、图表布局、准则、流程和页面特例
```

选择器使用类名和低特异性组合，避免元素选择器与组件类互相覆盖。页面特例不得反向修改通用组件默认行为。

## 7. 状态、错误与动效

- 保留 workspace 的 `busy`、`saving`、`error`、`message` 和请求序号语义。
- 加载态不得让旧数据假装成最新结果；页面保持结构并显示克制的加载提示。
- 错误信息继续使用可行动的中文文案，并在上下文区域展示，不只依赖短暂 toast。
- 成功 toast、对话框、空状态和只读提示使用同一视觉层级。
- 页面进入只使用约 `160–220ms` 的透明度和轻微位移动效；不引入动画依赖。
- `prefers-reduced-motion: reduce` 下关闭非必要过渡和位移。

## 8. 响应式与可访问性

- `≥1200px`：232px 完整侧栏，双栏分析布局。
- `768–1199px`：压缩侧栏与间距，保留图标和必要导航文字；分析卡片按内容调整为单列。
- `<768px`：侧栏成为顶部触发的抽屉，页面标题和操作垂直排列，卡片单列，数据表局部滚动。
- 保留跳到主内容链接、可见焦点、`aria-current`、对话框焦点恢复和语义按钮。
- 图表始终提供准确 `aria-label`；颜色不是状态或正负差异的唯一载体。
- 触控目标不小于约 40px，窄屏不允许除数据表外的整页水平滚动。

- 六个页面的正常、空数据和错误状态；
- 项目与月份切换、搜索、分页、导入、导出；
- 新建项目对话框、准则编辑、保存、冻结和派生版本；
- 键盘导航、焦点恢复、减少动效模式；

视觉验收以参考项目的结构纪律和信息密度为比较对象，不以像素复刻为目标。重设计后必须继续明确展示研究来源和局限。

## 10. 设计取舍

未采用完全照搬参考项目的红蓝院校体系，因为会造成品牌误认且不对应新能源汽车研究语义。未采用只修改现有颜色的保守方案，因为无法形成统一的页面模板和长期可维护的样式边界。

最终选择领域化迁移：保留参考项目的机构式秩序、紧凑密度和低装饰表面，以评论信号青、市场响应橙和证据链轨道形成观衡自己的识别系统。

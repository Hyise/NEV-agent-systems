# 实验结果接入情景与份额分析设计

## 目标

让自定义研究中已经完成的模型实验成为“情景分析”和“份额分析”的可追溯数据源，避免实验结果只停留在模型实验页。预置研究继续读取只读历史归档，不改变原有口径。

## 范围

- 份额分析允许选择已完成实验、模型和测试月份，展示该模型在所选测试月的真实样本份额与预测份额。
- BEAST-MCDM 在实验结果中保存按观察月份计算的准则权重、理性混合权重和有效时间压力。
- 情景分析允许选择已完成实验，并展示其中 BEAST-MCDM 的月度诊断曲线。
- 2026 年起有效时间压力为 0；由此产生的水平曲线必须正常显示并附带解释。
- 旧实验若没有月度诊断数据，应显示明确的兼容性提示，不伪造曲线。

## 非目标

- 不把模型实验结果复制进历史归档文件。
- 不自动挑选“表现最好”的模型，也不将测试结果描述为未来销量预测。
- 不修改原始评论、销量或已经冻结的评价矩阵。
- 不把不同实验、不同模型或不同月份的候选集混合归一化。

## 约束

- 自定义研究始终通过模型实验详情读取结果；预置研究仍通过 `/curves` 与 `/predictions` 读取归档。
- 实验列表继续省略大体积预测明细；用户选择记录后再请求详情。
- 份额图的分母沿用实验快照中当月入选车型的销量总和。
- BEAST 月度诊断是模型内部参数与函数值的复核材料，不代表消费者真实心理状态或政策因果效应。

## 方案比较

### 方案 A：前端直接消费版本化实验详情（采用）

扩展现有模型实验工作区，在选择实验时请求完整详情；两个分析页共享该状态。优点是实验 ID、快照、模型和月份关系明确，无需复制或发布数据；代价是页面需要处理旧实验兼容性和选择状态。

### 方案 B：把最新实验自动发布到旧 `/curves` 与 `/predictions` 接口

页面改动较少，但“最新”会随新运行隐式变化，破坏复核时的可追溯性，也容易把不同模型结果覆盖到同一入口，因此不采用。

### 方案 C：把实验结果复制成独立分析表

读取简单，但会形成第二份派生数据并引入同步、失效和删除策略，不符合当前本机研究版的简洁性，因此不采用。

## 数据设计

BEAST 模型结果的 `metadata` 新增：

```text
diagnostic_curves:
  weights: [{ month, pressure, values: { criterion: weight } }]
  rationality: [{ month, pressure, values: { criterion: coefficient } }]
```

`weights` 使用拟合后的全局准则重要度并按月份记录；`rationality` 使用拟合后的样条参数在每个观察月份的有效时间压力处求值。所有 2026 年月份的 `pressure` 均为 0。

## 页面行为

- 模型实验工作区默认选择最新记录，并加载其完整详情；切换记录时重新加载详情。
- 份额分析默认优先选择 BEAST-MCDM，否则选择该实验第一个有预测的模型；默认选择最后一个测试月份。
- 情景分析读取所选实验的 BEAST 月度诊断；缺少 BEAST、实验未完成或旧实验无诊断数据时给出针对性提示。
- 两页均展示实验短 ID、模型或诊断来源，确保用户知道当前看到的结果来自哪次运行。

## 验收标准

- 当前 V3 数据可重新运行实验，并在份额分析看到 2026-04 的车型份额明细。
- 情景分析可看到 2026-01 至 2026-04 的权重和理性混合曲线；因无时间压力可以是水平线。
- 切换实验、模型或月份后，页面只展示对应结果。
- 预置研究的 2025 年归档展示保持不变。
- 后端全量测试、前端单元测试、类型检查和生产构建全部通过。

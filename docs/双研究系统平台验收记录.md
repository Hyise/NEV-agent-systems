## 1. 交付范围

本轮把原多准则工作台纳入“观衡研究平台”，增加多准则决策与自适应评估两个入口。多准则模块完成独立路由、工作台壳层及六个页面的研究型界面重构；自适应评估当前只有事实准确的规划说明，不请求业务 API、不展示模拟指标。

模块注册、平台路由、多准则 workspace 与 API 已分层。平台层和自适应页不导入多准则状态；返回平台后，多准则未保存草稿由 `KeepAlive` 暂存。架构选择见 [ADR-0001](ADR/0001-双研究系统平台与模块路由.md)。

## 5. 已知边界

- 自适应评估尚未接入研究材料、业务对象、数据、算法或接口；当前页面不能用于实际评估。
- 多准则图表和实验指标仍来自原研究归档，不是当前服务重新训练结果；训练与评估月份重叠的限制继续随结果展示。
- 系统仍是无鉴权的本机单用户版本，只监听 `127.0.0.1`，不得直接开放公网。
- `KeepAlive` 只能在当前页面会话内暂存未保存草稿；关闭或强制刷新浏览器前应保存。
- 在服务运行期间重新构建前端后，已经打开的旧页面可能仍引用旧分包；刷新页面即可加载新构建。

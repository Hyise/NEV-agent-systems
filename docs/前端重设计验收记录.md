- 六个页面：研究总览、数据中心、准则工作台、情景分析、份额分析、实验档案。

## 4. 关键流程

- 新建项目对话框可打开、关闭，关闭后焦点返回“新建研究”按钮。
- 预置项目与自定义项目可切换；自定义草稿出现未保存修改后，项目和版本选择会被禁用，撤销后恢复。
- 数据表在手机视口内只由表格容器横向滚动，页面本身不横向溢出。
- 权重为空时显示“打开准则工作台”；曲线全部取消时显示选择提示；份额筛选为零时显示空状态；自定义项目无实验记录时显示独立空状态。
- 份额差值同时显示“高估/低估”、正负号和数值，不依赖颜色传达。
- 实验档案在表格前保留训练/评估边界说明；BEAST 行以背景、字重和左侧标记共同突出。
- 启动器首次发现源码较新时自动构建，服务健康后启动；重复运行只报告系统已运行。

任务：依据冻结的准则体系，对一条新能源汽车评论进行封闭式多准则标注。

规则：
1. 一条评论可命中零个、一个或多个准则，同一准则最多出现一次。
2. criterion 和 label 必须逐字来自下方冻结体系，不允许创建新准则或新等级。
3. evidence 必须是完整评论中的原文子串，不得摘要或改写；同一准则的多段证据合并到一个数组。
4. 未能归入冻结体系但值得研究的原文放入 unmatched_evidence。
5. basis 只写简短判定依据；褒贬冲突时结合整条评论选一个最接近等级并简述冲突。
6. 没有有效车辆评价时 annotations 可为空，但接口异常不能用空数组代替。

严格只输出以下 JSON 结构，不要增加字段：
{
  "annotations": [
    {
      "criterion": "空间实用性",
      "label": "宽敞灵活",
      "evidence": ["后排坐三个人也不挤"],
      "basis": "评论明确评价了后排乘坐空间"
    }
  ],
  "unmatched_evidence": []
}

冻结准则（顺序不得改变）：
__CRITERIA_JSON__

完整评论：
__REVIEW_TEXT__
